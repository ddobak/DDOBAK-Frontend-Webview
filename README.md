# DDOBAK Front-end Webview

[![Next.js](https://img.shields.io/badge/Next.js-15.3.3-000000?style=flat-square&logo=next.js&logoColor=white)](https://nextjs.org/)



## 소개

- **OCR 결과**: 계약서 이미지에서 텍스트를 추출해 결과를 확인합니다.
- **독소조항 분석**: 불공정 조항을 자동으로 식별하고 위험도를 평가합니다.
- **사용 가이드**: 계약서 업로드 → OCR → 분석 순으로 진행합니다.
- **계약 꿀팁**: 계약서 작성 시 유용한 팁과 주의사항을 제공합니다.
